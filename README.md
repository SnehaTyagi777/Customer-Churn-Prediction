# Customer Churn Prediction

A Machine Learning project that analyzes customer behavior and predicts whether a customer is likely to churn. The project uses data preprocessing, exploratory data analysis, customer segmentation, classification models, and model evaluation to identify customers who are at higher risk of leaving a service.

## Project Overview

Customer churn is an important business problem because losing existing customers can directly impact revenue. This project uses historical customer data to identify patterns associated with churn and build machine learning models that can predict customer churn.

The project also applies K-Means clustering to segment customers based on characteristics such as tenure, monthly charges, and total charges.

## Machine Learning Algorithms

### Logistic Regression
Used as a classification model to predict whether a customer will churn or stay.

### Random Forest Classifier
An ensemble learning algorithm that combines multiple decision trees to improve classification performance.

### K-Means Clustering
An unsupervised learning algorithm used to segment customers into groups with similar characteristics.
